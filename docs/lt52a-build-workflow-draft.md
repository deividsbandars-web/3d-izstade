# LT52A Build Workflow Draft

## Purpose
This is the first step-by-step build workflow draft based on the intended LT52A wall logic.

It is not a final construction manual.
It is a controlled workflow draft for:
- model logic;
- future cutting/schedule work;
- user build preparation.

## Phase 1: Base And Floor
1. set out final footprint
2. prepare supports/foundation concept
3. build floor perimeter beams
4. install floor joists
5. install blocking
6. close floor build-up

## Phase 2: Wall Primary Structure
1. place corner posts
2. place major perimeter members
3. place opening side posts
4. place head members over openings

## Phase 3: Main Wall Stud Grid
1. mark `600 mm` centers
2. install vertical studs
3. resolve exact edge conditions at corners
4. resolve exact edge conditions at openings

## Phase 4: Board / Sheathing Layers
1. install outer board/sheathing layer
2. install inner board layer where sequence requires it

## Phase 5: Insulation
1. fill main framed zones with mineral wool / stone wool
2. fill secondary zones if used in final assembly

## Phase 6: Exterior Openings
1. prepare window openings cleanly
2. prepare sliding door opening cleanly
3. install frames
4. install glazing / doors
5. check equal left/right finish conditions

## Phase 7: Exterior Cladding
1. set corner stop logic
2. set board module and gap rule
3. install vertical facade boards
4. trim around windows and doors
5. check that no tiny accidental strips remain

## Phase 8: Terrace
1. build terrace perimeter frame
2. install terrace joists/beams
3. install deck boards evenly
4. center stairs
5. finish edge conditions

## Phase 9: Roof
1. set final roof structure
2. install roof members
3. install roof board/skin layer
4. finish ridge and fascia
5. confirm roof sits above wall plate correctly

## Phase 10: Final Quality Checks
1. corners align
2. openings align
3. board rhythm aligns
4. terrace aligns
5. roof aligns

## What Must Be Fixed Before Final Cutting Tables
- final roof system
- final exterior board width/gap
- exact opening edge offsets
- exact corner strategy
- exact timber section classes
