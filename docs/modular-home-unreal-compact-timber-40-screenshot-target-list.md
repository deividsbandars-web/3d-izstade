# Compact Timber 40 Unreal POC Screenshot Target List

Status: review capture checklist for local Unreal production review.

## Required Exterior Targets

1. exterior hero three-quarter front
   - show pitched roof
   - show natural timber facade
   - show front deck

2. exterior straight-on entry view
   - show balanced windows
   - show front entry door

3. exterior terrace view
   - show deck proportions and trim

4. exterior rear/private side
   - show bedroom side character

## Required Interior Targets

5. entry to living/kitchen
   - show immediate quality impression

6. living/kitchen hero
   - show premium interior finish and furniture package

7. bedroom view
   - show bedroom zoning and window relationship

8. bathroom core view
   - show wet-core identity clearly

9. entry/storage angle
   - show compact layout credibility

## Required Technical Review Targets

10. module seam visibility check
    - seams readable but premium

11. facade board direction/detail check
    - confirms timber expression

12. roof edge/gutter detail check
    - confirms edge condition is not placeholder-only

13. window frame close-up
    - confirms frame depth and glass assignment

14. floor-to-ceiling material continuity check
    - confirms no visible broken slots

15. top-down/editor review shot
    - confirms module layout and camera framing

## Stretch Capture If Time Allows

- dusk lighting pass
- terrace-to-interior composition
- bathroom core service side
- walk path from entry to bedroom

## Capture Rules

- no Pixel Streaming screens required
- no web UI overlays required
- local Unreal viewport or packaged local build is sufficient
- keep at least one neutral daylight set for comparison across revisions
