# LT52A Wall Section And Framing Schedule Draft

## Purpose
This draft translates the intended LT52A wall architecture into a controlled framing and material schedule direction.

It is for:
- modeling discipline;
- later drawing development;
- later board/timber planning;
- user build workflow preparation.

This is not yet a final engineering cut list.

## Base Geometry
- overall length: `10.20 m`
- overall width: `5.10 m`
- wall height: `2.70 m`
- terrace depth: `2.40 m`
- source wall thickness baseline: `150 mm`

## Target Framing Logic
### Primary Structural Members
Use heavier members for:
- perimeter corners
- opening sides
- critical perimeter transitions

Working size class:
- `95 x 145 mm`

### Main Wall Stud Rhythm
Use:
- `45 x 145 mm`
- `600 mm` centers

Clarified interpretation:
- these are vertical structural studs;
- they sit behind the finished exterior cladding layer;
- the visible vertical facade boards are a separate finish/material schedule category.

### Secondary / Service Layer
Optional modeling class:
- `45 x 45 mm` or `45 x 70 mm`

Use only in technical mode unless later confirmed as part of final build-up.

## Conceptual Wall Section
Outside to inside:

1. exterior finish cladding boards
2. outer support/boarding layer
3. main stud zone with mineral wool
4. optional inner service layer with mineral wool
5. inner board layer

## Exterior Cladding Board Draft
Working visual direction:
- vertical boards

Working draft board class:
- finish board width: `120 mm`
- visible gap target: `8 mm` to `12 mm`
- finish board thickness class: `20 mm` to `25 mm`

This is a modeling draft, not a final procurement lock.

## Corner Strategy
Use:
- dedicated corner post / corner trim

Draft corner member class:
- `95 x 145 mm` primary corner post
- optional visible trim layer depending on final facade detailing

## Opening Framing Draft
### Window / Door Jambs
- heavy jamb members at both sides
- visually symmetric treatment
- no unplanned narrow leftover strip

Draft jamb class:
- `95 x 145 mm`

### Head Members
Draft head member class:
- `95 x 145 mm` visual class minimum

Final lintel/header sizing must be engineered separately.

## Rear Facade Draft
Current intended simplification:
- one medium-large rear main window
- one smaller functional rear window
- no extra small clutter window unless functionally justified

## Terrace Side Draft
- one large slider `SD1`
- one companion window `W2`
- no decorative crossbar in `W2`

## Draft Timber Schedule Categories

### Category A: Primary perimeter members
- corner posts
- opening jamb posts
- major head members

### Category B: Main wall studs
- repeating wall studs at `600 mm`

### Category C: Secondary service battens/studs
- only if technical assembly includes a secondary cavity

### Category D: Exterior cladding boards
- vertical finish boards
- separate from the structural stud grid

### Category E: Inner board layer
- interior board layer or lining boards

### Category F: Terrace framing
- perimeter beams
- joists
- stair stringers
- deck boards

### Category G: Roof framing
- roof beams/rafters
- roof deck/boards
- ridge/high line members
- fascia members

## What Is Needed Before Precise Saw-Cut Tables
To generate honest exact board-length tables, these must be fixed first:
1. final roof type
2. final wall assembly thickness
3. final opening sizes and exact edge offsets
4. final corner strategy
5. final cladding board width/gap rule
6. final terrace edge geometry

Without those, a precise saw list would be false precision.

## Draft Build Sequence
1. set base/floor frame
2. set perimeter heavy members
3. set repeating wall studs at `600 mm`
4. frame openings with heavy jambs and heads
5. add sheathing/board layers
6. place insulation zones
7. add exterior finish boards
8. add opening trims and window/door units
9. build terrace frame and deck
10. build roof frame and finish layer
