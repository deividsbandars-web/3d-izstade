# Expo Asset Intake

This folder is the staging area for assets that are candidates for the Warpala Web3D sponsor expo release path.

Structure:
- `tooling/` for compression or conversion inputs
- `props/` for unified boulevard prop packs
- `foliage/` for instance-friendly plants and small trees
- `skyline/` for coherent scenic skyline packs
- `sponsors/` for per-sponsor media deliveries

Rules:
- do not drop random final release assets directly into `public/`
- validate assets here first
- keep source packs, notes, and license metadata together
- only promote validated release-safe assets into runtime paths
